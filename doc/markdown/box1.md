# PixelForge UI 改版设计文档（确认版）

## 1. 文档说明

依据用户 Axure 原型（box1.rp + 5 张导出设计稿）及 2026-08-28 逐条确认的答复整理。
本版为**开发依据**，所有"待确认"均已消除。对应代码：`pixelforge/ui/`、`pixelforge/core/`。

## 2. 总体架构变化

- 主窗口从「Tab 工具型」改为「三页导航 + 对话式创作流」：
  左侧固定侧栏（新的创作 / 收藏夹 / 历史记录 / 历史缩略图列表 / 底部设置齿轮）。
- 设置从对话框改为**整页**（左侧子导航：返回 / 通用 / 提供商 / 关于）。
- 主题：手写浅色 + 深色两套 QSS（浅色 = 白底 + 青色强调色，深色由开发按浅色对应设计），
  "跟随系统"用 Qt 平台样式侦测，不引入第三方主题依赖。
- 语言：下拉仅「中文」占位，i18n 暂不实现（预留配置项）。

## 3. 新的创作（对话式创作流）

### 交互结构
- 主区为**聊天流**：用户提示词 = 右对齐青色气泡（悬停出 复制/编辑/删除 图标）；
  生成结果 = 图片卡片，卡片上方元信息行「用时：Xs · 模型名 · 日期」，卡片下操作：
  收藏（星）/ 下载 / 打开所在文件夹。
- 底部输入区：大输入框（占位"说出你的修改意见……"）+ 工具条：
  【+】上传参考图、模型选择、【生成模式】下拉、高级参数齿轮、发送按钮。
- 多张结果**并排卡片**显示，超出宽度时横向滚动（不换行堆积）。

### 生成模式（预设高级参数）
| 档位 | 语义 | 映射（开发建议，可调） |
| --- | --- | --- |
| 快速 | 低步数换速度 | num_inference_steps 取低档（如模型默认的 50%~），关闭 guidance 覆盖 |
| 标准 | 厂商默认 | 不发送高级参数，全部用模型默认 |
| 创造 | 高参考值保细节 | guidance_scale 取高档 + 步数取高档 |

- 各厂商支持的参数不同（Seedream/智谱/混元不支持 steps 类参数）：
  不支持时该档位退化为「标准」（静默忽略，不报错）。

### 对话记忆与图生图
- 文生图：只发文字。图生图：点【+】上传参考图 + 文字。
- **当前图片**机制：每轮生成的多张图默认「最后一张」为当前图，每张卡片可点选；
  用户只输入修改意见（未重新传图）时，以当前图作为参考图走图生图。
- 会话（session）持久化：
  - 点【新的创作】= 保存当前会话到本地并开启新会话；
  - 侧栏提供「恢复上次对话」入口，点击还原上一会话（含图片路径、当前图状态）。
  - 存储：`data/sessions/` 下 JSON（消息序列、图片路径、模型、模式、当前图索引）。

### 元信息
- 「用时」= 点击发送 → 图片落盘的时长；失败轮次只显示错误气泡，不显示用时。
- history 表新增 `duration` 字段（SQLite 迁移：ALTER TABLE 加列，旧记录为 NULL 不显示）。

## 4. 收藏夹

- 标题「收藏夹——你喜欢的都在此处」；按月分组（八月/七月，倒序），卡片 = 缩略图 + 收藏时间。
- 顶部：日期搜索框（输入日期过滤）+ 列表/筛选/刷新图标。
- **可点击时间轴**（右侧竖排）：条目如「(3) 八月」，点击后滚动定位并置顶该月分组。

## 5. 历史记录

- 表格列：时间（可点击排序）/ 提示词 / 模型 / 存储路径；行内操作：复制提示词、复制路径、打开图片。
- 顶部：日期搜索 + 刷新 + **导出 CSV** + **导出 JSON**（与现有 exporter 导出格式一致）。
- 右侧时间轴同收藏夹（月份 + 计数，点击跳转置顶）。

## 6. 设置（整页）

### 通用
| 项 | 说明 |
| --- | --- |
| 窗口色调 | 浅色 / 深色 / 跟随系统（默认跟随系统） |
| 语言 | 中文（占位，暂不实现 i18n） |
| 图片存储路径 | 点击修改，默认 data/images |

### 提供商（卡片墙）
- 每家一张彩色卡片：APIkey（掩码 + 眼睛切换）、URL 地址、【启用】勾选、"点击获取key→"链接。
- 卡片状态文案：已保存 →「当前APIkey已经保存，去实现你的创意吧~」；
  测试失败 → 红色「连接失败了，检查一下APIkey和URL？⚠」。
- 厂商 = 现有 7 家（硅基流动 / 千问 / 智谱 / 火山方舟 / MiniMax / 混元 / 自定义），
  设计稿中的"阿里云/字节跳动"即千问/方舟，**沿用现有名称不改**。
- 【启用】为**单选**：勾选一家即切换当前激活厂商（其余卡片自动取消勾选）。
- 保留【测试连接】（GET {base}/models）。自定义卡片额外有「模型 ID」字段（已实现，c75f2b3）。
- 底部：保存 / 取消。

## 8. 实施顺序（开发建议）

1. **内核侧**：history 表加 duration；会话存储（data/sessions）；
   生成模式预设映射；CSV/JSON 导出对齐。
2. **骨架**：主窗口三页导航 + 左侧栏 + 设置整页化 + 关于页。
3. **创作流**：聊天 UI + 当前图机制 + 会话保存/恢复 + 生成模式。
4. **收藏夹/历史记录**：月分组 + 时间轴跳转 + 日期搜索 + 导出按钮。
5. **主题**：浅/深双 QSS + 跟随系统 + 设置项接入。

## 9. 已确认决策记录（2026-08-28）

1. 生成模式 = 快速/标准/创造 三档预设参数。
2. 修改图片 = 以上一轮"当前图"作为参考图；多图时点选哪张改哪张，默认最后一张。
3. 启用 = 单选切换厂商（不聚合多厂商模型列表）。
4. 设计稿的阿里云/字节跳动 = 千问/火山方舟，沿用现有名称。
5. 历史导出 = CSV 和 JSON（与现有导出功能一致）。
6. 新的创作 = 开新会话，旧会话存本地，可从「恢复上次对话」还原。
7. 多图并排卡片，溢出横向滚动。
8. 深色主题配色由开发按浅色版对应设计。
9. 关于页署名：Made By Pi Agent + Deepseek + Me(Limeng) + Zcode + GLM。
