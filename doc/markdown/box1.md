## 4. 新的创作（Page 5）

### 页面目标
默认工作区。左侧为最近生成记录缩略图（提示词截断 + 时间），右侧为创作区。

### 布局与字段
| 区域 | 内容 |
| --- | --- |
| 左侧栏 | 历史缩略图列表：提示词（截断显示，如「画一只穿着宇航员服装的猫，赛博...」）+ 时间（「8月20日 17:56」）+ 模型名（「kwai-kolors 可图」） |
| 右侧主区 | 模式选择（生成模式）、提示词输入、模型/尺寸/张数、参考图（图生图）、生成按钮 |
| 结果区 | 预览图 + 用时显示（「用时：15s」）【新增：显示生成耗时】 |

### 业务规则
- 左侧历史列表与「历史记录」共用同一数据源（history.db）。
- 【开发建议】点缩略图可在结果区回看该图及其提示词。

## 5. 收藏夹（Page 6）

### 页面目标
展示收藏（Like）目录下的图片，按月份分组，支持按日期搜索。

### 布局与字段
| 内容 | 说明 |
| --- | --- |
| 月份分组 | 「七月」「八月」倒序分组头 |
| 时间轴 | 分组间以时间轴串联【新增：时间轴视觉元素】 |
| 图片项 | 缩略图 + 收藏时间（「8月19日 11:30」） |
| 搜索框 | 「输入日期来搜索相关图片......」【新增：按日期过滤收藏】 |

### 业务规则
- 数据源 = 图片目录下 `Like/` 子目录（沿用现有 favorite 机制）。
- 分组按收藏时间（文件时间）的年月归组。

## 6. 历史记录（Page 8）

### 页面目标
全部生成记录的检索视图，表格 + 时间轴 + 日期搜索。

### 列表字段
| 列 | 说明 |
| --- | --- |
| 时间 | 生成时间 |
| 提示词 | 生成时的提示词 |
| 模型 | 使用的模型 ID/名称 |
| 存储路径 | 图片本地路径 |

### 业务规则
- 搜索框按日期过滤（「输入日期来搜索相关图片......」）。
- 月份分组（八月/七月）+ 时间轴呈现，同收藏夹风格。
- 【开发建议】行点击可打开图片/定位文件（现有导出功能可复用）。

## 7. 设置（Page 9）

### 7.1 通用 Tab
| 字段 | 说明 |
| --- | --- |
| 窗口色调【新增】 | 浅色 / 深色 / 跟随系统，设定主色调 |

### 7.2 提供商 Tab
| 字段 | 说明 |
| --- | --- |
| 提供商列表 | 硅基流动 / 阿里云 / 字节跳动 / 自定义（现有实现为六家：硅基流动、千问、智谱、火山方舟、MiniMax、混元；原型中的「自定义」为【新增】OpenAI 协议自定义厂商） |

| API Key | 「点击获取key→」跳转厂商注册页（现有功能） |

### 7.3 操作与状态反馈
| 操作 | 行为 |
| --- | --- |
| 保存 | 暂存当前配置，提示「当前APIkey已经保存，去实现你的创意吧~」 |
| 取消 | 关闭且不保留未保存内容 |
| 连接失败 | 提示「连接失败了，检查一下APIkey和URL？」【开发建议：保存时做一次连通性校验】 |
